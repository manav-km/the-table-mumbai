# The Table — Mumbai
## Fine Dining & Farm-to-Table

A dedicated, zero-AI-slop web platform engineered for **The Table** in Mumbai.

### Key Features
- **Zero AI-Slop Design**: Tailored typography and palette reflecting The Table's authentic heritage.
- **Table & Seating Reservations**: Direct booking engine logging customer details, party size, and preferred dining time slots.
- **Direct Signature Ordering**: Verified house specialties with transparent INR pricing.
- **Direct Conversion Actions**: Click-to-call (`tel:`), turn-by-turn Google Maps navigation, and WhatsApp concierge integration with prefilled messages.
- **Accessibility**: Semantic HTML5 with WCAG 2.2 AA compliant contrast and responsive layouts (320px–1440px+).
